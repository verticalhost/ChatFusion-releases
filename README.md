# ChatFusion — Downloads

Installers and updates for **ChatFusion**, a multi-platform chat aggregator for
streamers. The application source code is maintained privately; this repository
only hosts the released installers and the update metadata.

## Download

Get the latest installer from the [releases](../../releases) page, run it, enter
your channel names, and paste the OBS links into a browser source.

The app updates itself: when a new version is published here, a banner appears in
the window with a button to install it.
